## Лабораторная работа №1: «Классы»
**Тема:** Реализация объектной модели данных и unit-тестов  
**Вариант:** №44 — «Ветеринарная клиника»

---

### Описание предметной области
В информационной системе ветеринарной клиники фиксируются данные о питомцах, их владельцах, ветеринарах и записях на прием:

* **Питомец (`Pet`):** кличка, биологический вид, порода, дата рождения, вес, владелец.
* **Вид животного (`AnimalSpecies`):** перечисление (`Cat`, `Dog`, `Bird`, `Rodent`, `Reptile`).
* **Порода (`Breed`):** справочник с привязкой к конкретному виду животного.
* **Владелец (`Owner`):** ФИО, телефон, адрес, список питомцев.
* **Ветеринарный врач (`Veterinarian`):** ФИО, номер паспорта, год рождения, стаж, специализация.
* **Специализация (`Specialization`):** справочник с привязкой к профильному виду животного.
* **Прием (`Appointment`):** дата и время, номер кабинета, признак повторного приема, ссылки на питомца и врача.

---

### Реализованный функционал
1. Разработана объектная модель данных с разделением на доменные сущности и интерфейсы.
2. Все публичные классы, методы и перечисления документированы XML-комментариями.
4. Реализован датасид с фиксированными данными.
5. Реализован сервис аналитических LINQ-запросов и покрыт юнит-тестами на xUnit v3:
   * Получение врачей по профильному виду животного.
   * Получение уникальных питомцев врача с сортировкой по кличке.
   * Подсчет количества повторных приемов для выбранной породы.
   * Выборка владельцев с несколькими питомцами с сортировкой по ФИО.
   * Выборка приемов за указанный месяц в заданном кабинете.
6. Настроен CI-пайплайн сборки и автоматического прогона тестов в GitHub Actions.
